Політика конфіденційності та захисту даних

Останнє оновлення: 2026 рік

1. Загальні положення

Платформа PsySoft (ПсіСофт) створена з першочерговим пріоритетом збереження терапевтичної таємниці, безпеки даних фахівців та їхніх клієнтів. Ми дотримуємося принципів мінімізації збору даних та максимальної локалізації збереження інформації.

2. Принцип зберігання даних та локалізація

  • Всі клінічні нотатки, протоколи сесій та персональні дані клієнтів зберігаються виключно у вашому зашифрованому особистому просторі (базі даних користувача).
  • Сервер PsySoft не використовує дані терапевтичних сесій для навчання сторонніх AI-моделей.
  • Аудіозаписи сесій не зберігаються на публічних або відкритих серверах.

3. Використання OpenAI API

Для транскрибації та допомоги у структуруванні протоколів сесій використовується офіційний API OpenAI. Згідно з офіційними умовами OpenAI API (Enterprise & API Privacy Terms), дані, надіслані через API, не використовуються для тренування публічних моделей OpenAI і видаляються з систем обробки після завершення запиту.

4. Захист інформації

Ми застосовуємо сучасні стандарти шифрування під час передачі даних (SSL/TLS). Доступ до вашого акаунту захищено персональною автентифікацією. Користувач несе відповідальність за збереження своїх доступів у безпеці.
